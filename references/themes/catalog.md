# Theme Catalog (starter directions)

Use to propose **2–3 initial directions** (Phase 2). This is NOT a per-page rotation — once chosen, a project holds one system. Each theme = palette + type roles + layout family.

| Theme | Feel | Layout family | Type roles (display / body / data) |
|---|---|---|---|
| **Editorial** | literate, trustworthy | asymmetric editorial, rules, generous space | high-contrast serif / humanist sans / mono labels |
| **Modern Minimal** | precise, calm | clean grid, hairline structure | grotesk display / neutral sans / mono |
| **Developer** | technical, trustworthy | dark surface, code-forward, spec lists | grotesk / sans / mono-heavy |
| **Atmospheric** | premium, immersive | dark AI-tool, glow, asymmetprofile | expressive display / neutral sans / mono |
| **Playful** | friendly, soft | rounded, high whitespace | rounded display / rounded sans / mono |
| **Brutal** | loud, memorable | hard borders, offset shadows, high contrast | heavy grotesk / grotesk / mono |
| **Newsprint** | editorial print | broadsheet columns, hairline rules | roman serif / serif / mono |
| **Terminal** | command-line | mono, phosphor, scanline (mild) | mono / mono / mono |
| **Bloom** | soft consumer | rounded cards, warm neutral | warm display / sans / mono |
| **Cobalt** | engineering near-white | split-studio, single cobalt signal | grotesk / neutral sans / mono |
| **Pixel** | 8-bit / retro | see `themes/pixel.md` | pixel display / pixel CJK + sans / mono |

## Selection cues
- Map brief signals → cluster: "editorial/docs" → Editorial/Newsprint; "dev tool" → Developer/Cobalt/Terminal; "AI/labs" → Atmospheric; "consumer/friendly" → Playful/Bloom; "loud/agency" → Brutal; "retro/game" → Pixel.
- Keep token *names* from the chosen theme's world (they aid the "guess the product" test).
- Every theme still passes all gates. A theme is a direction, not a license to break spacing/contrast/tokens.
