# Landing-page benchmarks (frozen) — tag: briefs-v1

All briefs share: single self-contained HTML, inline CSS/JS, ONLY Google Fonts, responsive, accessible, Chinese primary.
Each must include: top nav; hero (value prop + primary CTA); **a framed product visual (the "figure")**; 3 features; trust/social proof; footer.

## TRAIN (4)
### B1 · Nimbus — API 聚合网关（开发者工具）
OpenAI 协议兼容的多模型 API 网关：一个 Key 调多家模型（GPT/Claude/Gemini/DeepSeek/Qwen），文字/图片/视频，按量计费、逐次可追溯。

### L2 · Morrow — 单产地咖啡订阅（消费电商）
小批量、按季配送的单产地咖啡订阅：每期一款产区豆 + 冲煮卡，用户可在 App 里管理偏好与配送。

### L3 · Still — 助眠与冥想 App（移动应用）
用声音、呼吸与睡前故事帮助入睡的 App：睡眠报告、白噪音混音、睡前引导。

### L4 · Ledgerline — 数据合规 SaaS（企业 B2B）
帮企业做数据分类、保留策略与审计的合规平台：自动发现敏感数据、生成审计证据、对接内控流程。

## HOLD-OUT (2) — 只在里程碑 M4 跑一次
### H1 · Parcel — 独立乐队新专辑巡演（音乐/文化）
一支独立乐队发布新专辑与巡演：试听、巡演日程、周边预售、邮件订阅。

### H2 · Market Row — 本地农贸市集（社区/非科技）
社区农贸市集：本周末开市信息、摊位与农户介绍、线上下单自提、志愿者招募。
